Balancing Workbench

Balance an equation one pass at a time. Fill in a tally for each pass, check it, and the workbench tells you which row to fix next, when to use the odd-oxygen trick, and when you're done.

How to count and the order to fix rows
  • A subscript belongs to the element right before it. No subscript = 1.
  • A subscript outside parentheses multiplies everything inside.
  • A coefficient multiplies the whole formula, on top of the subscripts. Add up every formula on that side.
  • A polyatomic ion that is unchanged on both sides (like SO₄) gets its own row and counts as one unit. Its atoms are not counted again in the element rows.
  • Fix order: everything except H and O first, then H, then O last. Elements standing alone (Al, Cu, O₂) are set last.
  • A 2 on one side and a 3 on the other? Swap them as coefficients.
  • Odd oxygen with O₂? Double every coefficient you've already set (not O₂; it's set last), recount, then set O₂ = O needed ÷ 2.
  • Change coefficients only, never subscripts. Blank coefficient boxes count as 1.
