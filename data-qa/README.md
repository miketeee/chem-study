# Study Guide Q&A pages

One HTML fragment per homework, named after its slug: `hw07.html`, `hw08.html`, and so on.
Start it with an `<h1>`, then use `<h2>` for sections and `<ol><li>` for each question and answer.

To make the pill on the homepage live, set `"qa": "hw07"` for that homework in `data/manifest.json`
(it is `null` until a page exists, which shows the pill greyed out).
